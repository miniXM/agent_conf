单 HTML 示例

学习模块也可以只是文章网页

这篇示例故意做得很简单：一个 HTML 文件里放自己的样式和正文。应用第一次打开时把它缓存到本地，之后就能离线读。

为什么这种方式适合你

因为你现在不是要做课程系统，而是做一个“文章集合”。文章数量不多时，单文件 HTML 很直接：卡片列表只描述入口信息，正文则保持完全独立。

推荐的数据结构

{ "version": "2026-06-18-001", "cards": [ { "id": "article-001", "title": "第一篇文章", "cover": "https://...", "html": "https://.../article-001.html", "htmlVersion": "1" } ] }

应用侧做什么

  • 启动时拉取卡片列表，发现有新版本就更新本地。
  • 点开文章时下载 HTML 并缓存。
  • 下一次没网时，直接打开本地缓存的文章。

关键点只有一个：文章 HTML 尽量自带样式，少依赖外部资源。这样缓存一份文件就够了。
