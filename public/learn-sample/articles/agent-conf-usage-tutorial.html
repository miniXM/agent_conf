三步配置 agent_conf

不用从头读长说明。照着这三张图走：登录、准备 API Key、打开工具开关。

1 登录 2 拿到 API Key 3 启用工具
1

先登录账号

输入手机号或邮箱和密码。没有账号就点“注册新账号”。

想下次少输一次，就勾选“保存本地账号”。
2

看配置页有没有 API Key

顶部已经有隐藏的 Key，就可以直接开工具。没有 Key，再去“我的”页面生成。

工具卡片右上角的开关，就是写入配置的按钮。
3

没有 Key 就生成一个

到“我的”页面展开 API Key，点“生成 API Key”或读取已有 Key。

生成或读取后，回配置页打开 Codex、Hermes、LobsterAI 的开关。

记住一句：有 API Key 就开工具开关；没有 API Key 就先去“我的”页面生成。
